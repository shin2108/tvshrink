# TV Shrink

子供がテレビに近づきすぎるのを防ぐため、画面の一部にだけ映像を表示し、残りを黒背景にするWebアプリです。
iPhoneのSafariで開いてAirPlayで画面ミラーリングすると、テレビ側も黒背景＋小さい映像になります。

## 使い方（毎回）

### 1. Macでサーバーを起動する

```bash
cd /Users/gaoxin/Desktop/TVshrink && python3 -m http.server 8080
```

### 2. MacのローカルIPアドレスを確認する

```bash
ipconfig getifaddr en0
```

例: `192.168.1.23` のように表示されます。

### 3. iPhoneのSafariで開く

MacとiPhoneが同じWi-Fiに接続されている状態で、Safariに以下を入力:

```
http://<Macで確認したIP>:8080
```

例: `http://192.168.1.23:8080`

### 4. 動画を読み込む

画面下のパネルで「動画ファイル」「YouTube」「動画URL」のいずれかを選び、動画を読み込んで再生。

### 5. 枠のサイズ・位置を調整する

- 上部の帯（ドラッグで移動）を指でドラッグして位置を移動
- 右下の丸いハンドルをドラッグしてサイズ変更
- パネルのスライダー・プリセット（25%/40%/60%/100%）でも調整可能
- 設定は自動保存され、次回開いたときも同じ状態

### 6. AirPlayでテレビに映す

**重要**: 動画プレーヤー内のAirPlayアイコンは使わないでください（動画だけが単独でテレビに飛んでしまい、黒背景の効果が消えます）。

必ず **コントロールセンター → 画面ミラーリング** からテレビ（OLED55A2PJA）を選んでください。これでiPhoneの画面全体（黒背景＋小さい映像）がそのままテレビに映ります。

### 7. 準備ができたら「🔒 ロック」でパネルを隠す

子供がiPhoneを触っても枠が動かないようにロックできます。歯車アイコン（画面右下）でパネルを再表示できます。

## きれいに全画面表示したい場合

SafariのアドレスバーもミラーリングされてしまうのでURL入力後、共有ボタン →「ホーム画面に追加」でアプリのように起動すると、ブラウザのUIが消えて黒一色になります。

## 制限事項

- Netflix・YouTubeアプリなど他社アプリの映像はこの仕組みでは縮小できません（Webページ内に埋め込めないため）。対応できるのはローカル動画ファイル・YouTube（ブラウザ埋め込み）・直接リンクの動画URLです。
