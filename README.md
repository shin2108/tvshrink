# TV Shrink

子供がテレビに近づきすぎるのを防ぐため、画面の一部にだけ映像を表示し、残りを黒背景にするWebアプリです。
iPhoneのSafariで開いてAirPlayの画面ミラーリングをすると、テレビ側も黒背景＋小さい映像になります。

**公開URL: https://shin2108.github.io/tvshrink/**

Macでサーバーを立てる必要はありません。上のURLをiPhoneで開くだけです。

## 初回だけやること（iPhone）

1. Safariで https://shin2108.github.io/tvshrink/ を開く
2. 下部の共有ボタン → **「ホーム画面に追加」**
3. ホーム画面に「TV Shrink」アイコンが追加される

これでSafariのアドレスバーが消え、黒一色の全画面で起動するようになります（ミラーリングしたときテレビにアドレスバーが映りません）。
Service Workerでキャッシュされるため、2回目以降はネットが繋がっていなくても起動します。

## 毎回の使い方

1. ホーム画面の **TV Shrink** アイコンをタップ
2. 下部パネルで「動画ファイル」「YouTube」「動画URL」のいずれかを選んで動画を読み込む
3. 枠のサイズ・位置を調整する
   - 上部の帯をドラッグして移動
   - 右下の丸いハンドルをドラッグしてサイズ変更
   - スライダー・プリセット（25%/40%/60%/100%）でも調整可能
   - 設定は自動保存され、次回も同じ状態で開く
4. **コントロールセンター → 画面ミラーリング** からテレビ（OLED55A2PJA）を選ぶ
5. 「🔒 ロック」を押してパネルを隠す（子供が触っても枠が動かなくなる）
   - 歯車アイコン（右下）でパネルを再表示

## 重要な注意

動画プレーヤー内のAirPlayアイコンは**使わないでください**。動画だけが単独でテレビに送られて全画面になり、黒背景の効果が消えます。
必ず **コントロールセンターの「画面ミラーリング」** を使ってください。これでiPhoneの画面全体（黒背景ごと）がテレビに映ります。

※このアプリでは動画要素のAirPlay転送を `disableRemotePlayback` で無効化しているため、通常はプレーヤーにAirPlayボタンは表示されません。

## 音と映像がずれるとき

AirPlayミラーリングは映像と音を別々にテレビへ送るうえ、テレビ側の映像処理でさらに映像が遅れるため、
構造上ズレが起きやすいです。効果の大きい順に試してください。

### 1. テレビのブラウザで直接開く（最も確実・ズレが原理的に起きない）

OLED55A2PJAには**ウェブブラウザ**アプリが入っています。AirPlayを使わずここで直接開けば、
そもそも転送が発生しないのでズレません。

1. テレビのホーム画面 → 「ウェブブラウザ」を開く
2. `shin2108.github.io/tvshrink/` を入力
3. マジックリモコンのポインタで枠をドラッグ、または**十字キーで移動 / Shift+十字キーでサイズ変更**

※テレビのブラウザでは「動画ファイル」（iPhone内の動画）は使えません。YouTube・動画URLのみです。

### 2. テレビ側の「AVサウンド同期調整」で合わせる

すべての映像ソースに効きます。

設定 → 音声 → 追加設定 → **AVサウンド同期調整**

あわせて以下も映像の遅れを減らします。

- 設定 → 映像 → 追加設定 → **TruMotion を「オフ」**（映像処理による遅延が減る）
- 設定 → 一般 → **ゲーム最適化（インスタントゲームレスポンス）をオン**（遅延が最小になる）

### 3. アプリの「音ズレ補正」スライダー

パネル下部のスライダーで音声を最大1秒まで遅らせられます（映像より音が先に聞こえる場合に有効）。

**「動画ファイル」で読み込んだ動画のみ**有効です。YouTube・動画URLはブラウザの制約（CORS）で
音声を加工できないため効きません。その場合は上の 1 か 2 を使ってください。

### 4. Wi-Fi環境を整える

- iPhoneとテレビを**5GHz帯**のWi-Fiに繋ぐ（2.4GHzは電子レンジ等の干渉でズレやすい）
- iPhoneの他のアプリを終了する

## 制限事項

- Netflix・Amazon Prime・YouTubeアプリなど他社アプリの映像は縮小できません（Webページ内に埋め込めないため）。
- 対応するのは、ローカル動画ファイル / YouTube（ブラウザ埋め込み）/ 直接リンクの動画URL（.mp4など）です。
