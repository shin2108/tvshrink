# TV Shrink

子供がテレビに近づきすぎるのを防ぐため、画面の一部にだけ映像を表示し、残りを黒背景にするWebアプリです。
**テレビ（LG OLED55A2PJA）のブラウザで直接開いて使います。** YouTube向けです。

**URL: https://shin2108.github.io/tvshrink/**

AirPlayを使わないので、音と映像のズレは起きません。Macでサーバーを立てる必要もありません。

## 初回だけやること（テレビ）

1. テレビのホーム画面から **ウェブブラウザ** を開く
2. アドレス欄に `shin2108.github.io/tvshrink/` と入力
3. **お気に入り（ブックマーク）に登録** しておく

テレビだと判定されると、自動的に文字とボタンが大きい「テレビ用の表示」に切り替わります。

## 毎回の使い方

操作は基本的に**マジックリモコンのポインタ**（画面上のカーソル）で行います。

1. お気に入りから TV Shrink を開く
2. 「保存済み」のボタンを押して再生リストを選ぶ
   - まだ無い場合は、URL欄に再生リストのURLを入れて「読込」
3. 「幅」「高さ」のスライダーか、プリセット（25%/40%/60%）で大きさを決める
4. 「閉じる」でパネルをしまう
5. 見終わったらリモコンの **戻るボタン** でパネルを再表示

### リモコンのボタン操作（パネルを閉じているとき）

| 操作 | 動き |
|---|---|
| 十字キー | 枠を移動 |
| **OK（決定）** | 「移動」と「サイズ変更」を切り替え |
| 十字キー（サイズ変更モード） | 枠の大きさを変更 |
| 戻る | パネルの表示・非表示 |

いまどちらのモードかは、画面上部に一瞬表示されます。

## 動画を次々と見続ける

**再生リスト（プレイリスト）のURL**を読み込むと、1本終わるたびに**自動で次が再生**されます。
最後まで行くと先頭に戻ってループするので、放っておいても止まりません。

単独の動画の場合も、終了時に関連動画が枠内に表示され、
**リモコンのポインタで選べばそのまま枠内で次が再生**されます。URLを入れ直す必要はありません。

子供に見せるときは「**関連動画を同じチャンネルに限定**」にチェックを入れると、
関係ないチャンネルの動画が出てこなくなります。

## 登録済みの再生リスト（D Billions 英語）

テレビでURLを打たなくて済むよう、D Billions（英語チャンネル `@dbillions`）の再生リストを登録済みです。
「保存済み」のボタンを押すだけで再生が始まり、1本終わるごとに自動で次へ進みます。

| ボタン | 内容 |
|---|---|
| まとめ動画（長め） | 数曲つながった長い動画。操作なしで長く流したいとき向け |
| Baby DB | 参考にいただいた動画のシリーズ |
| 定番 | チャンネルの主要な楽曲 |
| 新しい順 | 全動画を新しい順に |
| Mini DB | Mini D Billions シリーズ |
| ヒーロー | スーパーヒーローもの |
| ファミリー | ファミリーもの |

縦長で枠に収まらない「shorts」は、あえて除外しています。

「関連動画を同じチャンネルに限定」は**最初からオン**にしてあります。
これにより関係のないチャンネルの動画が出てこず、D Billions だけが続きます。
他のチャンネルも見せたい場合はチェックを外してください。

## テレビで文字を入力しなくて済むようにする（おすすめ）

テレビのブラウザでURLを打つのは大変なので、**よく見る再生リストはMac側から登録**できます。

`playlists.json` を編集して push すると、テレビ側の「保存済み」に自動で並びます。

```json
{
  "playlists": [
    { "name": "アンパンマン", "url": "https://www.youtube.com/playlist?list=PLxxxxxx" },
    { "name": "しまじろう", "url": "https://www.youtube.com/playlist?list=PLyyyyyy" }
  ]
}
```

編集したら、`sw.js` の `CACHE_NAME` の数字を1つ上げてから:

```bash
cd /Users/gaoxin/Desktop/TVshrink && git add -A && git commit -m "feat: 再生リストを追加" && git push
```

反映まで1〜2分かかります。

なお、テレビ上で「＋ 今の再生リストを保存」を押して保存することもできます（そのテレビにだけ保存されます）。

## iPhoneからAirPlayで使う場合

テレビのブラウザが使えないとき（Amazonプライムなど）は、iPhoneから使うこともできます。
その場合はSafariで上記URLを開き、共有ボタン →「ホーム画面に追加」でアプリのように起動できます。

- 必ず **コントロールセンター → 画面ミラーリング** を使ってください。
  動画プレーヤーのAirPlayボタンを使うと、動画だけが全画面でテレビに送られて黒背景の効果が消えます。
- AirPlayでは音と映像がズレることがあります。パネルの「音ズレ補正」スライダー（動画ファイル読み込み時のみ有効）か、
  テレビの **設定 → 音声 → 追加設定 → AVサウンド同期調整** で合わせてください。
- Amazonプライム・Netflixは「**黒画面のみ**」モードとピクチャインピクチャ（小窓）を組み合わせて使います。
  これらのサイトは `x-frame-options` により枠内への埋め込みが禁止されているためです（実測確認済み）。

## 制限事項

- YouTube本体・Amazonプライム・Netflixの**サイトそのもの**は枠内に表示できません（各社が埋め込みを禁止しているため）。
  YouTubeは埋め込みプレーヤー経由なので問題ありません。
- テレビのブラウザでは、iPhone内の動画ファイルは使えません。
